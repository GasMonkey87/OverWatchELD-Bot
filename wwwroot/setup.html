OverWatch ELD Setup Guide

Step-by-step setup from install to full VTC operation

1. Download & Install

Go to the downloads page and install the latest version.
Download ELD
Run the installer and open OverWatch ELD.

2. Add Discord Bot

Invite the bot to your Discord server:
Add Bot
Make sure the bot has permissions:
  • Send Messages
  • Manage Threads
  • Read Channels

3. Link Your Driver Account

In the ELD app, go to VTC → Link and copy your code.
In Discord, type: !link YOURCODE
You will receive confirmation:
  • Driver linked
  • VTC connected

4. Login to Web Portal

Go to: https://overwatcheld.up.railway.app
Click Login with Discord.
Select your VTC and complete setup.

5. Main Dashboard

After login you will see:
  • Connection status
  • Driver dashboard
  • Quick actions (Logs, Messages, Documents)

6. Logs System

View and manage:
  • Duty status (ON / OFF / DRIVE / SB)
  • Daily logs
  • Certify logs

7. VTC Features

Live Map
  • Track drivers in real time
  • View locations
Fleet / Maintenance
  • Truck condition
  • Service tracking
Performance
  • Miles
  • Loads
  • Driver stats
Roster
  • Driver list
  • Roles (Driver, Admin, Owner)

8. Telemetry Setup (ATS)

Install ATS Telemetry SDK plugin.
Start American Truck Simulator.
Make sure telemetry is enabled:
  • Speed
  • Fuel
  • Damage
  • Location
Once connected, ELD will show:
  • Live driving status
  • Truck info
  • Load tracking

9. Companion App

At the bottom of ELD, copy your Companion URL: http://YOUR-IP:5234
Open it on your phone or scan QR code.
You now have:
  • Mobile duty controls
  • Live clocks
  • Dispatch access

You're Ready

Your system is now fully connected:
  • ELD Installed
  • Discord Linked
  • Telemetry Active
  • VTC Connected
